# N1Gateway 0.3.5 发布说明

发布日期：2026-11-28

作者署名：BI4BYF

## 本版目的

修复 0.3.4 实机安装后暴露的屏幕常亮初始化错误。此前两个运行选项开关在恢复持久化值之前绑定监听器，初始化过程会把屏幕常亮误写为关闭，存在无人值守时再次熄屏失联的风险。

## 主要变化

- 先恢复开机自启和屏幕常亮开关的保存值，再绑定变更监听器。
- 增加 `runtimeOptionsReady` 初始化保护，未完成初始化时拒绝持久化。
- 增加独立迁移键 `screen_always_on_init_fix_v3`，首次升级到 0.3.5 时一次性恢复 `screen_always_on=true`。
- 后续用户仍可在本地界面主动关闭屏幕常亮；迁移不会在每次启动时强制覆盖用户选择。
- 版本升级为 versionCode 11 / versionName 0.3.5。
- 保留微信风格只读页面、令牌登录、SSE、前台服务和开机恢复能力。

## 已完成验证

- 77 项 JVM 离线自测通过。
- 23 个源码/网页文件只读边界扫描通过。
- 14 项版本与微信风格 UI 门禁通过。
- APK v2/v3 签名验证、zipalign 和 aapt 版本清单检查通过。
- 真实 N1 覆盖安装成功；首次启动把 `screen_always_on` 从 `false` 纠正为 `true`。
- 前后台切换后设置未再翻转；CPU、Wi-Fi、屏幕三项锁均为 `HELD`，屏幕保持 `Awake / ON`。
- 局域网地址的 16 项 HTTP/API/SSE 检查全部通过，HT 应用保持禁用且无进程。
