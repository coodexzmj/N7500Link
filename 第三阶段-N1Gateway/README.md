## 本阶段要解决什么

把已经验证过的 N7500 蓝牙读取能力放进 N1 前台服务，让电脑浏览器和 iPhone Safari 通过家庭 Wi-Fi 或 Tailscale 查看同一份只读状态快照。

```text
PC / iPhone
    |
家庭 Wi-Fi 或 Tailscale
    |
N1Gateway 前台服务
    |
Bluetooth Classic / RFCOMM
    |
WENNUO N7500
```

第一版只做监控，不做远程发射，也不做远程设置。这样可以把服务常驻、鉴权、状态缓存、断线重连和网页展示先做稳，再决定是否进入后续写入阶段。

## 第一版明确不包含

- 远程 PTT、音频采集、音频播放或录音。
- 远程修改音量、扫描、信道 A/B、频率、亚音、带宽或功率。
- 信道记录写入、固件升级、工厂复位。
- HT 账号、HT 聊天室或 HT 官方服务器。
- 公网端口映射。

## 关键安全边界

1. 默认只监听 `127.0.0.1`，不默认开放局域网，更不监听 `0.0.0.0`。
2. 局域网或 Tailscale 模式必须在 N1 本地手动开启，并持续显示风险提示。
3. 外部访问必须携带独立访问令牌，不能使用 HT 账号或频道口令。
4. 网页和 API 不提供任何写电台、PTT、音频或固件接口。
5. 蓝牙 Socket 只允许 `RadioSession` 访问，网页线程不能直接发指令。
6. 快照必须带实例标识、revision、更新时间和过期标志，不能把旧值冒充实时状态。

## 当前实现与验收进度

### 已实现

- 独立前台服务 `GatewayService`，持有唯一蓝牙会话和只读网页服务。
- N7500 设备信息、设置、状态、音量、当前信道的只读读取。
- 通知注册、状态变化接收、串行命令调度和半包/粘包解析。
- `instanceId`、`revision`、更新时间、`stale` 过期标记和只读快照。
- 访问令牌哈希、HttpOnly Cookie、12 小时会话、失败限流和脱敏审计。
- 内置登录页、状态页、电脑/手机自适应页面和 SSE。
- 默认仅监听 `127.0.0.1:8710`，可手动选择明确局域网或 Tailscale IPv4，不绑定 `0.0.0.0`。
- 蓝牙断链按退避持续重连；连续 3 次读取超时主动重建 RFCOMM。
- 默认保持屏幕常亮，同时持有部分 CPU 唤醒锁和高性能 Wi-Fi 锁；停止服务时成对释放。旧设置会在 0.3.4 首次升级时一次性迁移为开启，用户之后仍可手动关闭。
- 本地状态面板显示 CPU/Wi-Fi/屏幕锁状态，以及蓝牙分段、完整 GAIA 帧、丢弃字节、TX、响应匹配、超时和合并计数；这些诊断不进入 HTTP 或 SSE。

### 已完成的基础实机检查

- APK 已安装到真实 N1，使用真实 N7500 完成只读连接。
- 已读取产品 ID、软件版本、当前信道、收发状态和音量；快照为实时状态。
- 通过 ADB 端口转发完成 16 项 HTTP/API/SSE 检查，包括匿名跳转、登录、Cookie、快照、`ready`、`snapshot`、`heartbeat` 和注销。
- 实际关闭再开启蓝牙一次，网关恢复到 `ONLINE / CONNECTED`。
- 0.3.3 完成一次受控真实 N1 重启：网关 36.67 秒重新出现，36.73 秒达到 `ONLINE / CONNECTED`，最终恢复 45.79 秒；开机服务、CPU/Wi-Fi 锁、N1Guard、HT 禁用和停止均通过。
- 0.3.4 离线自测 77 项通过；23 个源码/网页文件只读边界扫描通过；14 项版本/UI 门禁通过；APK 为 versionCode 10、versionName 0.3.4，签名和对齐验证通过。

### 尚未完成或不能宣称通过

- 0.3.3 在熄屏约两分钟后 ADB、HTTP 和 Ping 同时失联，整网段 TCP/8710 扫描找不到 N1；发送 3 次 Wake-on-LAN 后仍不可达。根因是 N1 固件整机深度休眠并断开 Wi-Fi，不是 HTTP 服务单独异常。原始失败记录保存在本机，不提交到仓库。
- 0.3.4 已改为首次升级默认开启屏幕常亮，但尚未在恢复在线的 N1 上完成实机 2 小时长稳。
- N7500 实际断电 3 次仍未执行；N1 重启已通过 1 次，开机自启、CPU/Wi-Fi 锁、N1Guard、HT 禁用和停止均通过。
- 实际电脑与 iPhone 的局域网/Tailscale 页面、双客户端 revision 和移动端布局尚未完成。
- 抓包/日志只读字节复核、内存趋势和 30 分钟解析异常统计尚待形成结论。
- 因此 G1-A 至 G1-G 不能写成全部通过；0.3.4 当前是“代码与 APK 验证完成，实机熄屏修复待复测”。
