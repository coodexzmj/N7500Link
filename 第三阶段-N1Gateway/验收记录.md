## 4. 0.3.3 熄屏长稳失败

0.3.3 的屏幕常亮仍为关闭，熄屏长稳开始后很快失联：

- ADB 状态变为 `offline`。
- HTTP `/healthz` 连续 20 秒超时。
- Ping 返回 `DestinationHostUnreachable`。
- 整个网段 TCP/8710 扫描没有发现 N1。
- 发送 3 次 Wake-on-LAN Magic Packet，10 秒后仍不可达。
- 网关此前提示锁状态为 `CPU=HELD Wi-Fi=HELD`。

结论：根因是 N1 固件在整机深度休眠时断开 Wi-Fi，不是 HTTP 服务单独异常。CPU 锁和 Wi-Fi 锁不能替代屏幕常亮，且当前 N1 没有可用的远程唤醒通路。

长稳 CSV 只有 4 个失败样本，测试已取消，不能标记为通过。证据文件保留在本机：`v033-longstability-20261128-013318.csv`。

## 6. 0.3.5 实机修复验证

0.3.4 覆盖安装到真实 N1 后发现偏好的实际值为：

```text
screen_always_on=false
screen_always_on_default_v2=true
boot_enabled=true
```

根因是两个运行选项开关在 `setChecked()` 恢复保存值之前就绑定了监听器，初始化过程调用 `persistRuntimeOptions()`，把未完成初始化的屏幕开关值写回偏好。
