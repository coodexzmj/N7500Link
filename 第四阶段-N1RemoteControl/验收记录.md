## 4. 0.4.0 三项受限写入（控制逻辑未变更）

0.4.1 没有改动 `LowRiskWriteController`、`GaiaCodec` 写白名单、设置块处理或控制 API，因此没有在 0.4.1 重复执行三项写入。以下是通过记录来自 0.4.0 的真实 N1/N7500 上机结果，用作当前控制逻辑的回归基线。

每项操作都执行“读取基线 → 一次目标写入 → 延迟回读确认 → 恢复原值”。扫描和 A/B 的写入基于完整原始设置块，只修改对应状态位。

| 操作 | 目标写入与回读 | 恢复写入与回读 | 结论 |
| --- | --- | --- | --- |
| 音量 | `3 → 4`，`READBACK_OK` | `4 → 3`，`READBACK_OK` | 通过 |
| 扫描 | `OFF → ON`，`READBACK_OK` | `ON → OFF`，`READBACK_OK` | 通过 |
| A/B | `A → B`，`READBACK_OK` | `B → A`，`READBACK_OK` | 通过 |

正常测试期间三项均未触发自动回滚，控制状态中的 `rollbackSent=false`。这只证明正常写入链路和主动恢复通过；“回读不一致后自动回滚”路径尚未通过实机故障注入验证。

## 7. 当前结论

0.4.1 已经完成以下闭环：

1. 111 项离线门禁、APK 签名与清单检查通过。
2. 真实 N1 覆盖安装为 0.4.1 / versionCode 16，前台服务、屏幕常亮和 N7500 蓝牙连接正常。
3. 安卓原生界面改为单屏 + 左侧固定菜单，五个菜单逐页切换通过。
4. 1920×1080 下每页完整显示且没有上下滚动，旧上翻/下翻/到底入口和滚动实现已移除。
5. 控制逻辑保持 0.4.0 已验证的音量、扫描、A/B 三项范围；本版没有重新执行写入。

因此本版本可以作为第四阶段当前“原生单屏界面 + 三项低风险控制”的运行版本发布，但不能据此开放 PTT、音频、频率/亚音/带宽或信道记录写入。上述高风险能力仍需独立设计、故障注入和专门验收。
