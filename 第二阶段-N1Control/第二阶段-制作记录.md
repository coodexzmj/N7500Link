## 1. 本阶段定位

第一阶段已经通过只读探针确认了 N7500 的蓝牙连接和 GAIA 基本收发链路，但只读取设备信息、设置、状态、音量和信道，不修改电台。

第二阶段在此基础上增加了“可回读确认、失败可回滚”的最小写入能力。本阶段的重点不是远程控制，也不是 HT 聊天室或音频互通，而是先在 N1 的 Android 系统上验证独立 APK 可以安全控制 N7500 的少量低风险字段。

本阶段允许：

- 读取设备信息、设置、状态、音量和信道记录。
- 写入音量，并主动回读确认结果。
- 通过 `WRITE_SETTINGS` 切换扫描开关。
- 通过 `WRITE_SETTINGS` 选择已经保存的信道 A 或 B。
- 恢复写入前的音量和完整设置块。
- 对同一音量执行 50 次写入/回读稳定性自检。

本阶段明确禁止：

- PTT 按下和释放。
- 音频采集、接收和发射。
- WebSocket、网络服务、HT 账号或 HT 服务器。
- `WRITE_RF_CH` 信道记录写入。
- 频率、亚音、带宽、功率和信道名称编辑。
- 固件升级。
- C4FM 或其他语音解码。
- 未确认状态下的自动盲重试。
- 并发写入。

APK 不申请 `INTERNET` 权限。

## 2. 实现内容

### 2.1 应用与界面

- 新建第二阶段独立工程，没有修改第一阶段 `N1Probe`。
- 应用名改为“N1Control N7500 低风险控制”。
- 包名改为 `com.bi4byf.n7500link.control`，可与第一阶段的只读探针分别安装。
- 主界面集中展示连接、设备信息、设置、状态、音量、信道、写入状态、稳定性自检、原始收发记录和环境报告。
- 蓝牙设备优先从 N1 系统已配对列表中读取。
- 所有收发帧、解析结果、写入前状态、回读结果、回滚结果和自检进度都写入应用专属目录中的日志文件。

### 2.2 只读快照

连接成功后自动读取：

1. 设备信息 `GET_DEV_INFO`
2. 设置 `READ_SETTINGS`
3. 当前信道 `READ_RF_CH`
4. 电台状态 `GET_HT_STATUS`
5. 音量 `GET_VOLUME`

读取失败时保留原始帧，不根据猜测补造数据。

### 2.3 音量写入状态机

每次写入都执行同一流程：

```text
单写锁
→ 读取当前音量作为基线
→ 只发送一次 SET_VOLUME
→ 等待约 900 ms
→ 主动发送 GET_VOLUME 回读
→ 回读值与目标一致才判定成功
→ 不一致只回滚一次
→ 回滚后再次主动回读
```

读取基线失败、发送失败、回读失败或回读值不符时，不会继续执行后续写入。回滚也失败时只记录结果，不进入无限重试。

### 2.4 设置写入状态机

扫描和信道 A/B 选择都使用 `WRITE_SETTINGS`，但不会从零重建设置块。程序先读取完整设置，再复制原设置块，只修改目标位：

```text
payload[0] = 信道 A 低半字节 | 信道 B 低半字节
payload[1] = 扫描位 0x80 | 双信道位 0x30 | 静噪低 4 位
payload[9] = 信道 A 高半字节 | 信道 B 高半字节
```

写入后必须同时满足：

- 目标字段解析值正确。
- 完整设置块与预期写入负载逐字节一致。

两项都一致才判定成功。失败时只使用写入前保存的完整设置块回滚一次。

### 2.5 协议修正

原 HT APK 中的 `SET_IN_SCAN` 负载 `0/1` 实际用于蓝牙发现扫描，不是信道扫描。第二阶段没有使用 `SET_IN_SCAN` 切换信道扫描，而是使用 `READ_SETTINGS` / `WRITE_SETTINGS` 中设置块的扫描位。

### 2.6 请求关联防护

N7500 的 GAIA 响应没有独立请求编号。如果在同一命令已有请求在途时再次发送相同命令，晚到的响应可能被交给错误的处理流程。

为此增加防护：

- 同一 GAIA 命令同时只允许一个请求在途。
- 重复请求会被日志记录并拒绝，不发送到电台。
- 正常收到响应、发送失败或超时后释放该命令。
- 写入期间“刷新快照”按钮禁用，避免与写入状态机争抢同一读取命令。

### 2.7 安全边界

- 所有发送命令经过显式白名单。
- 任何状态写入前必须取得单写锁。
- 不发送 PTT、音频、`WRITE_RF_CH`、`SET_IN_SCAN` 或固件命令。
- APK 清单不含网络权限。
- 蓝牙断开、应用退出或用户主动断开时，未完成写入会判定为失败并停止。
- 调试签名仅用于本机测试，不作为正式发布签名。

## 4. N1 实机检查

0.2.1 已在 Phicomm p230（Android 7.1.2 / API 25）上完成以下检查：

- 清单已改为横屏，N1 的 1920 × 1080 界面可完整显示连接区域。
- 应用实际安装版本为 0.2.1，versionCode 3。

这次实机检查没有执行音量写入、扫描切换、A/B 切换或 50 次稳定性自检，因此不能把第二阶段描述为完整写入验收通过。
