N1Control N7500 第二阶段安装与实机验证说明
版本 0.2.1 / 包名 com.bi4byf.n7500link.control / 作者 BI4BYF

一、本版本能做什么
1. 读取 N7500 设备信息、设置、状态、音量和信道记录。
2. 写入音量并主动回读确认。
3. 切换扫描开关，并回读完整设置块。
4. 在已经保存的信道 A/B 之间切换，并回读完整设置块。
5. 恢复写入前的音量或完整设置块。
6. 对同一音量执行最多 50 次写入/回读稳定性自检。

本版本不会发送 PTT、音频、WRITE_RF_CH、固件升级或任何网络请求。
安装包没有 INTERNET 权限。

二、安装前准备
1. N1 保持 Android 系统，并已能通过 ADB 访问。
2. N7500 已在 N1 的系统蓝牙设置中完成配对。
3. 完全退出 HT 手机版，确认它没有占用 N7500 蓝牙连接。
4. 使用合法频率、合适假负载或受控天线环境。
5. 操作人员应能在测试期间随时切断电台电源。

四、安装与启动
1. 先确认设备已在线：
C:\adb-n1\platform-tools\adb.exe devices -l

2. 如果 N1 使用网络 ADB，按实际地址连接：
C:\adb-n1\platform-tools\adb.exe connect <N1局域网IP>:5555

3. 安装新版：
C:\adb-n1\platform-tools\adb.exe install -r "C:\Users\Zhang minjun\Desktop\N7500\第二阶段-N1Control\dist\N1Control-N7500-v0.2.1-debug.apk"

4. 启动：
C:\adb-n1\platform-tools\adb.exe shell am start -n com.bi4byf.n7500link.control/.MainActivity

五、首次连接
1. 打开 N1Control，允许定位权限。Android 7.1 读取蓝牙设备信息需要该权限。
2. 从已配对设备列表中选择 N7500。
3. 点击“连接 N7500”。
4. 等待自动只读快照完成。
5. 确认设备信息、设置、状态、音量和信道都有解析结果。
6. 检查“原始收发记录”中能看到 TX/RX 十六进制记录。

如果连接失败，先确认 HT 手机版已完全退出、蓝牙已开启、N7500 未被其他设备占用。

六、实机验收步骤

试验 1：只读快照
1. 连接后点击“刷新快照”。
2. 记录设备信息、设置、当前信道、状态和音量。
3. 确认日志中没有连续超时、解析失败或大量丢弃字节。
通过标准：五项读取都能完成，原始帧完整保留。

试验 2：音量写入与回读
1. 先记录当前音量。
2. 选择一个与当前值相差 1 档的有效目标音量，不要一次跳到极端值。
3. 点击“写入并回读音量”。
4. 等待操作状态显示“已回读确认为 X / 15”。
5. 点击“恢复上次音量”。
6. 确认回读结果恢复为写入前的值。
通过标准：写入成功必须由回读值证明；恢复也必须由回读值证明。

试验 3：扫描切换
1. 先读取当前设置，记录扫描状态。
2. 点击“切换扫描状态”。
3. 确认操作结果显示完整设置块回读一致。
4. 点击“恢复上次设置”。
5. 确认扫描状态和完整设置块恢复。
通过标准：目标字段正确，且非目标设置字节没有变化。

试验 4：信道 A/B 切换
1. 确认设置快照中的 A 和 B 都是预期信道。
2. 点击选择信道 A，等待回读确认。
3. 点击选择信道 B，等待回读确认。
4. 点击“恢复上次设置”，恢复原状态。
注意：切换当前信道可能改变电台的收发频率，测试前必须确认两个信道的频率、功率和使用环境都安全。
通过标准：当前信道按预期切换，完整设置块回读一致，恢复成功。

试验 5：50 次稳定性自检
1. 在前四项都通过后再执行。
2. 点击“开始 50 次音量稳定性自检”。
3. 不要同时点击刷新或执行其他写入。
通过标准：50 次逐次写入/回读全部完成；任一次失败时程序立即停止且不盲重试。

七、取回日志
C:\adb-n1\platform-tools\adb.exe pull /sdcard/Android/data/com.bi4byf.n7500link.control/files/N1Control-logs "C:\Users\Zhang minjun\Desktop\N7500\第二阶段-N1Control\实测日志"

日志应包含：
- 每次 TX/RX 原始十六进制。
- 命令名、状态码和负载。
- 写入前值、目标值、回读值和回滚结果。
- 稳定性自检的逐次进度。
- N1 型号、Android 版本、ABI 和蓝牙状态。

八、失败处理
1. 立即停止后续写入，不要连续点击重试。
2. 如果界面提供“恢复上次音量”或“恢复上次设置”，且连接仍正常，执行一次恢复。
3. 如果蓝牙断开或应用退出，先切断电台电源再检查。
4. 保存并拉取日志。
5. 不要用本版本尝试 PTT、音频或远程发射。
